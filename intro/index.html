CRM Customer API

Welcome to the CRM Customer API. This API allows you to manage customer records by creating, viewing, updating, and deleting customer information. All API routes return JSON responses except this home route.

Available Endpoints

  1. GET /customers - Returns a list of all customers.
  2. GET /customers/{id} - Returns a single customer by ID.
  3. POST /customers - Creates a new customer.
  4. PUT /customers/{id} - Updates an existing customer by ID.
  5. DELETE /customers/{id} - Deletes a customer by ID.
